# Overview

This is the first public release of Film2Trakt, a Chrome Extension that seamlessly integrates FilmAffinity with Trakt, it has been tagged as v0.9.

## Key features

- **One-click Trakt Search**: Adds a "Search on Trakt" button to FilmAffinity movie/series pages, allowing you to quickly find the title on Trakt.
- **Automatic Title Extraction**: Automatically grabs the movie or series title from the FilmAffinity page to pre-populate the Trakt search.
- **Series/Movie Detection**: Intelligently determines if you're viewing a movie or a series on FilmAffinity and directs the search to the appropriate section on Trakt.

## Installation

1. Download the `film2trakt_v0.9.5zip`.
2. Unzip the downloaded file.
3. Open Chrome and navigate to `chrome://extensions`.
4. Enable "Developer mode" in the top right corner.
5. Click "Load unpacked" and select the directory containing the unzipped extension files.
6. The Film2Trakt extension is now installed and active.
