# Guía de Seguimiento de Documentación Crítica del Proyecto

Esta tabla sirve como guía para la revisión y actualización regular de los documentos clave del proyecto, asegurando que la documentación se mantenga precisa y relevante.

| Nombre del Documento             | Frecuencia de Seguimiento        | Acción/Propósito del Seguimiento                                            |
| :------------------------------- | :------------------------------- | :-------------------------------------------------------------------------- |
| `README.md` (Raíz)               | Por Hito / Release               | Actualizar resumen, estado, instalación y uso rápido para nuevos usuarios.  |
| `docs/requirements.md`           | Por Hito / Cambio de Alcance     | Validar alineación con el alcance actual; añadir/modificar FR/NFR.          |
| `docs/features.md`               | Continuo / Por Feature           | Reflejar con precisión la funcionalidad implementada o modificada.          |
| `docs/project_structure.md`      | Por Hito / Refactorización Mayor | Asegurar que la descripción de la arquitectura y diagramas estén al día.    |
| `docs/setup_and_installation.md` | Por Hito / Cambio Dependencias   | Verificar que las instrucciones de configuración/instalación son correctas. |
| `docs/usage_guide.md`            | Por Hito / Release               | Confirmar que la guía de usuario coincide con el comportamiento actual.     |
| `docs/changelog.md`              | Por Release (Obligatorio)        | Registrar cambios (Added, Changed, Fixed) para la nueva versión.            |
| `docs/to_do_list.md`             | Semanal / Continuo               | Revisar progreso, añadir/eliminar/actualizar tareas pendientes.             |
| `docs/development_notes.md`      | Continuo / Por Decisión Clave    | Capturar nuevo contexto, decisiones de diseño o soluciones relevantes.      |
| `N00_project_tracking.md` (Este) | Mensual / Trimestral             | Revisar si la guía de seguimiento sigue siendo adecuada y completa.         |
